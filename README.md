# Clarity Clinical

Clarity Clinical is a research and demonstration prototype exploring how clinical decision support can improve consultation workflows while preserving clinician judgement and patient safety.

> **Demonstration system. Synthetic data only. Not clinically validated. Not a medical device. Not for diagnosis or treatment.**

## Stack

- Angular 19
- .NET 10 / ASP.NET Core 10
- EF Core 10
- PostgreSQL
- Npgsql
- SignalR

## Status

Early prototype development.
